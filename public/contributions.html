Contributions

Cryptic Realm is its own game, but it can still send practical engine improvements back upstream. This page separates shared ClaudeCraft-friendly work from private Cryptic Realm features.

Shared Upstream Candidates

These are the kinds of changes that should be offered as clean pull requests because they help the base project without giving away Cryptic Realm-only economy, realm, or lore systems.

Auth & Account SafetyOIDC wiring, optional TOTP login hardening, safer login throttles, clearer dashboard sessions.
Admin & Moderator ToolsAccount review, chat moderation, report queues, role-gated dashboards, and better status panels.
Updates & OperationsAuto-update maintenance mode, static cache policy, API health checks, and safer server restarts.
Wiki & Public HubsPublic wiki hub fallback, release/news feed, launcher status page, and improved nav consistency.
Game UI QualityCamera options, mobile layout fixes, clearer landing flows, and performance guidance.
Test CoverageSecurity tests, OAuth tests, realm tests, launcher tests, and visual smoke scripts.

Cryptic Realm-Only Work

These stay in the private/independent track because they define this game and should not be handed over as generic upstream value.
